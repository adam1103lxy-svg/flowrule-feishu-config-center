# FlowRule 飞书规则配置中心

FlowRule 是面向飞书群消息规则的 SaaS 闭环平台：配置飞书应用授权连接后，平台自身实时监听来源群消息，按已发布规则在执行时机（run_at）到期时自动调用飞书 Task v2 创建待办、回读核验创建结果，并向结果通知群发送待办链接。全程无需外部部署，所有执行过程均可在运行中心与审计中查看。

在线地址：<https://stayfoolish.feishu.link/app/app_17gu5bknjhu>

## 核心流程

1. **授权连接**：在连接中心配置飞书应用 App ID / App Secret，通过配置检查后平台开始实时监听来源群消息。
2. **配置规则**：在规则列表新建规则，配置来源群、触发与排除条件、业务对象提取、负责人策略、执行时机、待办标题内容、结果通知群与去重键。
3. **发布规则**：规则通过发布校验后形成版本，进入实时生效状态；支持版本历史与回滚。
4. **自动执行**：平台在 run_at 到期时自动调用飞书 Task v2 创建待办（幂等 client_token），回读核验创建结果，并向结果通知群发送待办链接。
5. **可观测**：消息接收、任务调度、待办创建与结果通知的全过程记录在运行中心与审计中，可按状态、规则与时间筛选追溯。

## 安全说明

- 飞书应用 App Secret 只在服务端加密存储，界面与接口均不回显；列表、日志与导出内容中仅出现掩码后的 App ID。
- 平台调用飞书 OpenAPI 均在服务端完成，凭证不经过浏览器。
- 外部接入使用的妙搭 Open API Key 由应用管理员在平台侧创建并绑定，原始 Key 仅创建时展示一次，丢失只能吊销后重建；本应用界面不管理、不存储任何密钥。

## 飞书应用权限要求

在飞书开放平台创建的应用需开通以下权限（以飞书开放平台后台实际权限项为准）：

- **接收群消息**：用于实时监听来源群消息；
- **创建与读取待办（Task v2）**：用于到期自动创建待办并回读核验创建结果；
- **发送消息**：用于向结果通知群发送待办链接。

在连接中心完成 App ID / App Secret 配置并通过配置检查后，闭环即开始运行。

## 外部接入（可选扩展）

外部拉取 API 为可选扩展，运行 SaaS 闭环无需任何外部部署。供需要在自有系统中运行已发布规则的外部系统使用：

- 配置拉取 API：`GET /openapi/v1/published-config`（妙搭 Open API Key 网关鉴权，可用）；
- 导出 JSON：在接入中心导出当前发布配置文件（可用）；
- 发布 Webhook：规划中，当前未启用。

详见接入中心页面或「下载接入文档」中的完整说明。

## 开发与运行

环境要求：Node.js >= 22，npm >= 10。

```bash
npm install          # 安装依赖
npm run dev          # 本地开发（前后端同时启动）
npm run dev:server   # 仅启动后端（NestJS watch）
npm run dev:client   # 仅启动前端（Vite）
npm run type:check   # 前后端类型检查（tsc --noEmit）
npm run lint         # 代码检查
npm run build        # 构建
```

- 后端：NestJS 单模块 `server/modules/flowrule/`，PostgreSQL 持久化（Drizzle ORM）。
- 前端：React 19 + react-query，页面位于 `client/src/pages/`。
- 前后端共享契约：`shared/api.interface.ts`。
